# Demo CLI: `civicclerk`

## Goal

A console command that demonstrates the library's capabilities against any
tenant, doubling as living documentation (feedback item 7). A user installs
the package, runs `civicclerk <subcommand> <tenant>`, and sees the library's
surface exercised for real — plus a guided `demo` tour that narrates a full
walk of the API.

## Requirements

- `civicclerk` console script installed with the package; `--help` shows
  subcommands and each subcommand's `--help` documents its options.
- Subcommands mirror the client surface: `categories`, `events` (with
  `--category`, `--from`, `--to`, `--limit`, default limit 15, `0` means
  everything), `agenda` (indented section/item tree with attachment
  counts), `text` (best-effort file text), `download` (file to a path).
- Human-readable output by default; `--json` dumps the raw API payloads
  (demonstrating the `.raw` escape hatch).
- `demo <tenant>` narrates a tour: categories → recent events → an agenda
  tree → a document's extracted text, printing the equivalent Python for
  each step as it goes; skips gracefully when a tenant lacks data (no
  agendas, no files).
- Library errors exit non-zero with a one-line message on stderr (no
  tracebacks for `CivicClerkError`); usage errors exit with argparse's
  standard code 2.
- Unit-tested through `main(argv)` with injected transports — no real
  HTTP in the default suite.

## Out of scope

- No new runtime dependencies (no rich/click/typer, no color).
- No config files, env-var tenants, shell completion, or output paging.
- No changes to the client/models beyond what the CLI consumes.
- No async, no auth-required endpoints.

## Constraints

- stdlib argparse only; the CLI module lives at `libcivicclerk/cli.py`,
  entry point `civicclerk = libcivicclerk.cli:main` in pyproject.
- Testability: `main` accepts an argv list and a client factory
  (defaulting to `CivicClerkClient`) so tests inject mock-transport
  clients; stdout/stderr asserted via capsys.
- The CLI keeps the client's default pacing (politeness is part of the
  demonstration); `--limit` bounds output count, not request rate.
- Dates parse as ISO (`YYYY-MM-DD`); invalid input is an argparse error,
  not a traceback.
- Public-repo rule: examples and help text use fictional tenants only.
- Docs site gets a CLI page; README gets a short section (it stays the
  complete quickstart per the docs-site decision).

## Environment

- `uv run pytest` / `prek run --all-files` — unchanged gates.
- `uv run civicclerk --help` — exercise the entry point locally.
- `uv run --group docs mkdocs build --strict` — docs gate.
